# VuePizza

Учебный проект [HTML Academy](https://htmlacademy.ru): веб-приложение для заказа пиццы на Vue 3. Пользователь собирает пиццу в конструкторе, добавляет её в корзину и оформляет заказ.

**Статус: в процессе.**

## Что реализовано

- Конструктор пиццы: тесто, размер, соус, ингредиенты, итоговая цена по данным с сервера.
- Добавление ингредиентов кнопкой «+» и перетаскиванием (drag-n-drop).
- Корзина: список пицц и дополнительных товаров, изменение количества, итоговая сумма.
- Маршрутизация (Vue Router), хранилище состояния (Pinia).

## Что ещё не сделано

- Анимации (переходы между страницами, поп-ап, drag-n-drop).
- Тесты.
- Данные о доставке: самовывоз, новый адрес, существующий адрес.
- Авторизация с валидацией формы.
- Оформление заказа, история заказов, повтор заказа.
- Страница «Мои данные»: адреса доставки.

## Стек

Vue 3, Vite, Pinia, Vue Router, JavaScript.

Вёрстка и серверная часть (Node.js, PostgreSQL, Docker) предоставлены курсом.

## Как запустить

Нужны Docker и Node.js 16 или новее.

```bash
git clone https://github.com/AnastasiiaXX/vue-pizza.git
cd vue-pizza
docker compose build
docker compose up
```

- Клиент: http://localhost:8080
- Сервер: http://localhost:3000
- Документация API (OpenAPI): http://localhost:3000/explorer/

Тестовый пользователь для входа: `user@example.com` / `user@example.com`.

Запуск только фронтенда (при работающем сервере): `cd frontend && npm ci && npm run dev`.
